# Security

Do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting for this repository when it is available. If it is disabled, contact the maintainer through their GitHub profile and request a private reporting channel. Include a short description and steps to reproduce. Do not include real customer data, credentials, or payment information.

This project is a work in progress. Do not deploy it with real customer or payment data until the production checklist in the README is complete.
